# 🎤 Voice To Text App

A simple and powerful **Voice to Text Web Application** that converts spoken words into written text in real-time using browser-based speech recognition.
This project demonstrates how to use modern web technologies to build an interactive and accessible voice input system.


## 🚀 Features
- 🎙️ Real-time speech-to-text conversion  
- ⏱️ Instant transcription while speaking  
- 📝 Displays recognized text dynamically  
- ▶️ Start / Stop voice recording  
- 📱 Responsive and user-friendly UI  
- ⚡ Fast and lightweight  

## 🛠️ Tech Stack
- **HTML5**
- **CSS3**
- **JavaScript (Vanilla JS)**
- **Web Speech API (Speech Recognition)**

## ⚙️ Installation & Setup
1.Clone the repository - git clone https://github.com/amansingh9598/Voice-To-Text-App.git
2.Open the project folder - cd Voice-To-Text-App
3.Run the project - Open index.html in your browser

## 💡 How It Works
Uses the Web Speech API for speech recognition
Captures audio input from the microphone
Converts speech into text in real-time
Updates the UI dynamically with recognized text

👉 The Web Speech API enables browsers to process voice input and convert it into text using built-in speech recognition engines.
